# Data folder

Download the Kaggle dataset **HR Analytics: Job Change of Data Scientists** by arashnic:

https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists

Place `aug_train.csv` in this folder.

Expected path:

    data/aug_train.csv

`aug_test.csv` is optional and is not used for model evaluation because it does not contain the target label.

The source CSV files are excluded from Git tracking so the repository stays lightweight and avoids unnecessary redistribution of the dataset.
