# Presentation-Day Checklist

## Night before
- Copy the entire project folder to the laptop and a USB drive.
- Keep the ZIP as a third backup.
- Run `VERIFY_PROJECT.bat`.
- Run the presentation once with Wi-Fi turned off.
- Rehearse to 7:20–7:40, not 7:59.
- Keep charger and HDMI/USB-C adapter ready.

## 15 minutes before presenting
1. Plug in charger.
2. Disable notifications / Focus mode.
3. Close WhatsApp, mail, ChatGPT and unrelated tabs.
4. Double-click `RUN_PRESENTATION.bat`.
5. Confirm `http://127.0.0.1:8000` opens.
6. Press `D` and run both High-intent and Low-intent examples.
7. Press `R` to reset timer.
8. Return to Scene 1.
9. Press `F` for fullscreen.

## During presentation
- Right Arrow / Space = next scene.
- Left Arrow = previous scene.
- D = jump to live demo.
- R = reset timer.
- Esc = detailed Explore/Viva mode.
- P = return to Presentation Mode.

## If the model demo fails
- Do not debug in front of the faculty.
- State: “The local backend is unavailable, so this screen is showing the labelled demo fallback; the trained model and API are part of the submitted package.”
- Continue immediately to results.

## If the projector fails
- Have the website open on the laptop and the PPTX in `resources/` as a conventional backup.
